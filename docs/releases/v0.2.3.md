# 墨隐阅读 v0.2.3

## 更新内容

- 修复在 125%/150% 等非整数显示缩放（如 Windows 150%）下，按住正文拖动窗口时窗口被不断拉大的问题。拖动现在只移动窗口，尺寸保持不变；个别缩放比例下开始拖动时尺寸可能有 1–2 像素的一次性校正，属正常现象。
- 更新元数据（`latest*.yml`）内置纯文本更新说明，旧版本客户端检查更新时不再显示原始 Markdown/HTML 标记。
- 更新面板中的更新说明改为可折叠区域，长内容可在区域内滚动，不再撑开面板。

## 下载与安装

- Windows：`moying-novels-0.2.3-x64-Setup.exe`；旧安装版也可通过“检查更新”升级。
- Apple Silicon（M 系列）：`moying-novels-0.2.3-arm64.dmg`。
- Intel Mac：`moying-novels-0.2.3-x64.dmg`。
- 保留原有书架、阅读进度和设置，无需删除应用数据。

macOS 使用 ad-hoc 签名，未配置 Apple Developer ID 签名及公证，首次运行仍可能被系统拦截，仍需手动替换安装。

维护提示：请保留 Release 中的 `latest*.yml` 与 `.blockmap` 附件，它们是更新功能的配置与配套文件，不是多余安装包。
