# 墨隐阅读 v1.0.3

## 更新内容

- “×”按钮改为完全退出应用：关闭窗口即退出进程（包含 Alt+F4），退出前自动保存阅读进度和窗口位置，不再隐藏到托盘。
- “—”仍为最小化；托盘图标点击仍是显示/隐藏窗口，托盘菜单保留“显示/隐藏”与“退出”。
- 更多菜单中的“隐藏到托盘”更名为“退出应用”。

## 下载与安装

- Windows：`moying-novels-1.0.3-x64-Setup.exe`；旧安装版也可通过“检查更新”升级。
- Apple Silicon（M 系列）：`moying-novels-1.0.3-arm64.dmg`。
- Intel Mac：`moying-novels-1.0.3-x64.dmg`。
- 保留原有书架、阅读进度和设置，无需删除应用数据。

macOS 使用 ad-hoc 签名，未配置 Apple Developer ID 签名及公证，首次运行仍可能被系统拦截，仍需手动替换安装。

维护提示：请保留 Release 中的 `latest*.yml` 与 `.blockmap` 附件，它们是更新功能的配置与配套文件，不是多余安装包。
