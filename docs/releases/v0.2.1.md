# 墨隐阅读 v0.2.1

- 修复 macOS 打包时跳过重新签名、安装后可能提示“文件已损坏”的问题，改为显式 ad-hoc 签名。
- 保持 Hardened Runtime，配置 Electron 主应用与子组件所需运行权限。
- 发布前校验两个架构的 DMG、ZIP 内应用签名及架构，并对原生架构进行 Electron 加载测试；失败时阻止发布。
- 保持书架、阅读进度、设置和 Windows 更新方式不变。

## 下载与安装

- Windows：下载 `*-x64-Setup.exe`，或在 0.2.0 的“检查更新”面板更新。
- Apple Silicon（M 系列）：下载 `*-arm64.dmg`。
- Intel Mac：下载 `*-x64.dmg`。
- Mac 用户请退出旧版，将新版拖到“应用程序”替换；无需删除阅读数据。

注意：macOS 的 ad-hoc 签名不是 Apple Developer ID 签名或公证，首次运行仍可能被系统拦截，macOS 仍采用手动更新。此版本修复签名完整性问题，不承诺消除所有 Gatekeeper 提示；不要全局关闭系统安全保护。
