# 墨隐阅读 v0.2.2

## 更新内容

- 正文任意位置按住左键拖动窗口，工具栏空白处也可拖动；单击仍显示/收起阅读控制浮层。
- 区分单击与拖动，避免松手后误弹工具栏；取消正文文字划选，不影响按钮、滚轮与边缘缩放。
- 拖动期间暂停自动滚动与鼠标移出隐藏，松手后恢复；失焦、窗口隐藏或取消拖动时清理交互状态。
- 手动阅读到章末后继续向下滚动或按 Page Down，自动进入下一章；触控板短时间重复滚动不会立即连续跳章。
- 自动滚动在最后一屏留出阅读时间后续章，最后一章读完自动停止；设置或目录打开时暂停自动滚动。
- 改善切章和重新打开小说时的滚动位置恢复与进度保存。
- Windows 检查更新时先比较版本，已是最新版时显示“当前已是最新版本，无需更新。”；区分缺失更新配置与一般网络失败。

说明：完全隐藏并开启鼠标穿透时，仍不能直接点击拖动窗口；本次支持的是正常阅读与正文可见的透明阅读状态。

## 下载与安装

- Windows：`moying-novels-0.2.2-x64-Setup.exe`；旧安装版也可通过“检查更新”升级。
- Apple Silicon（M 系列）：`moying-novels-0.2.2-arm64.dmg`。
- Intel Mac：`moying-novels-0.2.2-x64.dmg`。
- 保留原有书架、阅读进度和设置，无需删除应用数据。

macOS 使用 ad-hoc 签名，未配置 Apple Developer ID 签名及公证，首次运行仍可能被系统拦截，仍需手动替换安装。

维护提示：请保留 Release 中的 `latest*.yml` 与 `.blockmap` 附件，它们是更新功能的配置与配套文件，不是多余安装包。
