# 墨隐阅读 v1.0.2

## 更新内容

- 修复安装版中捐赠面板不显示收款码的问题：此前收款码资源在打包环境下加载失败并被自动隐藏，现在改为随应用打包并实测验证。
- 正文阅读区上下增加呼吸间距，文字不再紧贴窗口上下边缘，留白与阅读背景无缝衔接；唤出工具栏时的过渡动画保持不变。

## 下载与安装

- Windows：`moying-novels-1.0.2-x64-Setup.exe`；旧安装版也可通过“检查更新”升级。
- Apple Silicon（M 系列）：`moying-novels-1.0.2-arm64.dmg`。
- Intel Mac：`moying-novels-1.0.2-x64.dmg`。
- 保留原有书架、阅读进度和设置，无需删除应用数据。

macOS 使用 ad-hoc 签名，未配置 Apple Developer ID 签名及公证，首次运行仍可能被系统拦截，仍需手动替换安装。

维护提示：请保留 Release 中的 `latest*.yml` 与 `.blockmap` 附件，它们是更新功能的配置与配套文件，不是多余安装包。
