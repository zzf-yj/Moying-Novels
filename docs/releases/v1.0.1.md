# 墨隐阅读 v1.0.1

## 更新内容

- 新增捐赠入口：书架底部“捐赠 ♥”打开收款码面板，喜欢的话可以请作者喝杯咖啡，完全自愿。
- 新增老板键：全局快捷键（默认 Ctrl + Alt + B），在任何界面按下立即退出进程、窗口瞬间消失；可在设置中更换按键或关闭。
- 版本更新面板全新设计：当前/最新版本对比卡片、彩色状态提示、平滑下载进度条与更清晰的按钮层级。
- 开发模式使用独立数据目录，可与正式安装版同时运行。

## 下载与安装

- Windows：`moying-novels-1.0.1-x64-Setup.exe`；旧安装版也可通过“检查更新”升级。
- Apple Silicon（M 系列）：`moying-novels-1.0.1-arm64.dmg`。
- Intel Mac：`moying-novels-1.0.1-x64.dmg`。
- 保留原有书架、阅读进度和设置，无需删除应用数据。

macOS 使用 ad-hoc 签名，未配置 Apple Developer ID 签名及公证，首次运行仍可能被系统拦截，仍需手动替换安装。

维护提示：请保留 Release 中的 `latest*.yml` 与 `.blockmap` 附件，它们是更新功能的配置与配套文件，不是多余安装包。
