# 墨隐阅读 v1.0.0

首个稳定版本。阅读体验全面升级为连续滚动模式，窗口几何在各类显示缩放下保持稳定。

## 更新内容

- 正文改为连续滚动阅读：向下滚动到章节末尾时，下一章内容自动续接在下方，无需跳切；向上滚动到章节开头时，自动衔接上一章的末尾，阅读位置保持不动。
- 阅读进度按“章节 + 章内位置”保存，跨章滚动、重启应用后精确恢复到原来的阅读位置。
- “上一章”“下一章”按钮和目录跳转改为瞬时切换，直接定位到目标章节开头。
- 修复在 125%/150% 等非整数显示缩放下，拖动或拉伸窗口时窗口尺寸逐帧抖动（±1 像素）并引起正文反复重排的问题；现在窗口边界始终落在整数物理像素上，拖动完全平稳。
- 自动滚动沿连续内容平滑推进，读完全书最后一屏后自动停止。
- 开发模式使用独立的数据目录，可与正式安装版同时运行，互不干扰。

## 下载与安装

- Windows：`moying-novels-1.0.0-x64-Setup.exe`；旧安装版也可通过“检查更新”升级。
- Apple Silicon（M 系列）：`moying-novels-1.0.0-arm64.dmg`。
- Intel Mac：`moying-novels-1.0.0-x64.dmg`。
- 保留原有书架、阅读进度和设置，无需删除应用数据。

macOS 使用 ad-hoc 签名，未配置 Apple Developer ID 签名及公证，首次运行仍可能被系统拦截，仍需手动替换安装。

维护提示：请保留 Release 中的 `latest*.yml` 与 `.blockmap` 附件，它们是更新功能的配置与配套文件，不是多余安装包。
